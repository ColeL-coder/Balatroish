# Phase 00 — Mission Brief (Canonical)

## One-Sentence Mission
Design a mobile-first roguelike poker deckbuilder that preserves chips × multiplier hand scoring, differentiates through Sigils, and uses Constellation Weaving as support without replacing poker play.

## Player-Frequency Focus
Most frequent actions, in order:
1. read draw state
2. evaluate poker hand options
3. play/discard under target pressure
4. interpret score source attribution
5. make between-round build decisions

## Emotional Promise
- Early: curiosity + discovery
- Mid: control + elegance
- Late: spectacle + inevitability

## Non-Negotiables
- poker-hand decision centrality
- clear chips × multiplier language
- escalating pressure readability
- strong shop/deck decision impact
- Sigils as the primary identity layer
- portrait-mobile one-second clarity

## Success Condition
A new teammate can explain in one minute:
- what this game is
- what is distinct
- what can never be sacrificed
