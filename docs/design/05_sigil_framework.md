# Phase 05 — Sigil Framework

- hard cap 6 to protect readability

common, refined, rare, mythic, celestial, corrupt.

dormant, bound, awakened, exalted, corrupted, fused, split, shattered.

## Trigger Taxonomy
hand type, suit, rank, first hand, discard discipline, retrigger, enhancement interaction, boss interaction.

## Anti-Bloat Rule
