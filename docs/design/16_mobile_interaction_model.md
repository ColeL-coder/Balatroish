# Balatroish — Phase 16 Mobile Interaction Model

## Core Goals
One-thumb comfort, clear touch affordances, low precision frustration.

## Primary Inputs
- tap inspect
- drag/tap-select cards
- large play/discard actions
- tap/hold Sigil details
- swipe shop rows
- hold boss icon for disruption preview

## Environmental Requirement
Playable in short sessions, intermittent attention, no audio, outdoor light.
