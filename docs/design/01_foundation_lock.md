# Phase 01 — Foundation Lock

## Pillar A: Familiar Poker Core
Hard rule: never introduce mechanics that make poker-hand evaluation secondary.

## Pillar B: Sigils as Identity Engine
Hard rule: if a Sigil can be replaced by a generic passive with no loss, redesign.

## Pillar C: Portrait-Mobile Clarity
Hard rule: if spectacle harms clarity, clarity wins.

## Cross-Pillar Gate
A feature is approved only if it:
- deepens poker decisions
- strengthens Sigil identity
- preserves mobile readability
- keeps cognitive load and pace healthy
